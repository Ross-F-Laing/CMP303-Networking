Server Build contains the build of the server. Run this first.
Client Build contains the build of the client. Run this second to connect a client to the server

Steps:
Run the server.
Run your client once server has started
Enter a username and press connect
Press "ESC" to lock your mouse to the window then click to focus on the window
Controls are WASD to move and space to jump
Left click to shoot (no visual for this but you can shoot enemies and they will die)
Picking up an item allows you to throw a grenade, once you have picked up an item right click to throw it
